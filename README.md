Entry for the [One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72) bounty on make.fun.

`main.py` writes one word to `/output/entry.txt`:

> Teenager

Home Wi-Fi behaves like a teenager: it shuts itself in its room, only works on its own terms, ignores you when you need it most, and emerges exactly when it feels like it. Full bars in the kitchen, nothing in the bedroom; fine all morning, gone the second your video call starts.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
